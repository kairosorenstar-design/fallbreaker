Cómo jugar FallBreaker

FallBreaker combina dos juegos clásicos en una sola pantalla: arriba caen piezas estilo Tetris, abajo una barra de rompeladrillos las golpea con una bola para destruirlas.

Controles

Teclado
  • Flechas izquierda / derecha: mover la pieza
  • Flecha arriba: girar la pieza
  • Flecha abajo: acelerar la caída
  • Barra espaciadora: lanzar la bola
  • Tecla P o Escape: pausar
  • Mouse: mover la barra, clic para lanzar la bola
Pantalla táctil
  • Desliza el dedo para mover la pieza en esa dirección
  • Desliza hacia abajo y mantén para acelerar la caída
  • Toca sin deslizar: gira la pieza (o lanza la bola si está esperando)
  • En la zona inferior, el dedo mueve la barra

Objetivo de cada nivel

Cada figura se rompe con tantos golpes de bola como cubos tiene. Cada nivel pide destruir una cantidad de figuras; los bloques falsos no cuentan para esa meta, así que identificarlos a tiempo importa.

Consejos para mejorar

  • Mira el indicador "Sig" para planear dónde encajar la siguiente pieza.
  • El contorno tenue debajo de la pieza muestra dónde va a caer: úsalo para no perder tiempo.
  • Si vas en racha (combo), evita perder la bola: cada figura seguida suma más puntos.
  • La bola se acelera conforme avanzas en el nivel. Si atrapas la desventaja de bola rápida, prioriza defender antes que atacar.
  • Si fallas varias veces seguidas en un nivel, el juego te va a ofrecer bajar la dificultad solo para ese nivel.
